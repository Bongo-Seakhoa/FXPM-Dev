Recommended profile · 2026-04-30

FxPM 1.4 — Best Config Recommendations

Target operator: $10K–$50K equity · MT5 broker · Windows host
Profile philosophy: balanced specialist tournament + lightweight institutional shell + fail-closed live
Source: walks every key in config.json against the post-v2 codebase.
How to read this document. Each setting is tagged keep if the current value is what I'd recommend, tune if I'd change it, strict if it's a non-negotiable safety knob, and info for environment-specific values. The Recommended column gives the value I'd set; the Why column gives one or two sentences of operator-level reasoning.
What this profile optimizes for. Long-term capital preservation while letting the specialist tournament keep its edge. It is not the most aggressive configuration possible. If you have a $5K account and want to compound fast, raise position.risk_per_trade_pct to 1.5–2.0; if you have a $50K+ account and want survival above all, drop it to 0.5–0.75. The discovery layer is risk-invariant in this profile (discovery_risk_per_trade_pct = 1.0 is fixed), so changing live risk does not re-rank winners.

3. Cost modelling

KeyTypeRecommendedWhy

use_commission keepbooltruePer-lot commission applies to most ECN brokers. Set to false only on spread-only accounts (commission is embedded in the spread there).
use_slippage keepbooltrueApplies only on stop exits (market orders). TP exits are limit fills with no slippage.
slippage_pips keepfloat0.5Conservative for major FX. If live logs show consistent >1 pip slippage on stops, raise to 1.0; if <0.2, lower to 0.3 to avoid pessimistic backtests.

5. FX scoring & validation thresholds

KeyTypeRecommendedWhy

26. Instrument specs & symbol list

The 62-entry instrument_specs block and symbols list are environment data, not tunable knobs. Recommended treatment:

  • instrument_spec_defaults.commission_per_lot: 7.0 is right for ECN brokers; ECN-Plus or commission-free brokers should set this to their actual rate (often 0).
  • instrument_specs[SYMBOL]: keep as fallbacks. The MT5Connector overrides these with broker-reported values on connect, so they only matter offline / for symbols MT5 can't resolve.
  • swap_long / swap_short: refresh from broker quarterly. They drive the swap model and stale values silently bias D1/exotic backtests.
  • spread_avg: fallback baseline used by the spread filter when rolling median isn't yet established. Keep close to your broker's typical spread; e.g., 1.0 for EURUSD majors, higher (5–30) for exotics and indices.
  • symbols: 62 is a generous universe. For a fresh live deployment I'd start with the top 12 most-liquid pairs/indices (EURUSD, GBPUSD, USDJPY, USDCHF, USDCAD, AUDUSD, NZDUSD, EURJPY, EURGBP, XAUUSD, US100, US500), prove out the supervisor and cycle-drift behaviour, then expand.
